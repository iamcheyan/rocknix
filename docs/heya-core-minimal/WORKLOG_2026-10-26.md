### 3.2 控制脚本 `rocknix-services`

`projects/ROCKNIX/packages/rocknix/sources/scripts/rocknix-services`（安装到 `/usr/bin`）：

```
rocknix-services list
rocknix-services status KEY
rocknix-services start|stop KEY
rocknix-services toggle KEY
rocknix-services set KEY on|off
```

内部表格格式 `setting|systemd units|start command`，同时写回 `system.cfg`，是这些开关的唯一写入者。未知键以退出码 2 拒绝。

### 3.3 开机流程

1. `autostart/098-devservices`（新增）：读取开关，启动已启用的服务；无 unit 的（avahi、adbd）走命令启动。
2. `autostart/099-networkservices`（原有）：遍历 `/usr/lib/autostart/daemons/*`，把 `*.enabled=0` 的 unit 停掉。

`daemons/` 目录本次新增，由 `rocknix/package.mk` 的 `post_install` 安装到 `/usr/lib/autostart/daemons`：

`003-avahi`、`010-http`、`015-rsyncd`、`020-ftp`、`028-telnet`

### 3.5 升级迁移

`/storage/.config/system/configs` 被 `post-update` 的 rsync 排除，新键永远到不了旧卡。在 `sources/post-update` 末尾追加：

```sh
# 只补缺失键；已存在的选择（例如用户关掉的 ssh）保持不变
for key in $(grep -o "^[a-z0-9._]*\.enabled=" /usr/config/system/configs/system.cfg); do
  grep -q "^${key}" "${SYSTEM_CFG}" || printf '%s\n' "$(grep "^${key}" /usr/config/system/configs/system.cfg)" >> "${SYSTEM_CFG}"
done
```
