# ROCKNIX 启动器 Switch 风格重构 — 实机验收截图

本目录收录掌机屏幕截图。文件名按验收阶段编号：

- `01`–`05`：第一版界面各页，依次展示首页、媒体、游戏、设置和系统页面。`06-current.png` 与 `step1.png`–`step4.png` 也记录了当前界面及操作过程中的屏幕画面；截图只呈现各自帧中的内容。
- `10`–`11`：更换新宿主二进制后的首页画面及 probe 阶段画面（`10-newhost-home.png`、`11-probe0.png`–`11-probe2.png`）。
- `20`–`24`：逐屏切换测试画面，分别对应首页、媒体、游戏、设置和系统页面。
- `30`–`41`：按键响应测试画面。`30-base.png` 与 `40-base.png` 是基准帧，`31-*` 与 `41-*` 文件名标注对应测试的 L1、方向键、R1 或 START；截图记录测试时的屏幕状态。

## 已验证

- 状态栏显示真实读取到的 IP 地址 `192.168.3.57` 和电量 `100%`（分别来自 `ip` 命令与 `/sys/class/power_supply`）。
- 卡片不再被屏幕右边缘裁切。

## 已知未解决问题

- 实机上按 START、R1 或方向键均完全没有响应，输入链路处于失效状态。
- 底部提示栏仍有字体缺字形的方框字符。
